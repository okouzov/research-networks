# R&E·NET — Мрежите на науката / The Networks of Science

Двуезичен (BG/EN) статичен сайт за изследователските и образователните мрежи (NREN/RREN) по света и в ЕС.
Без build стъпка и без framework: чист HTML + CSS + JavaScript, данни в JSON. Работи на GitHub Pages и на всеки статичен хостинг.

## Стартиране локално

Сайтът зарежда JSON с `fetch`, затова трябва да се отвори през уеб сървър (не като `file://`):

```bash
python -m http.server 8519 --directory research-networks
```

После отворете http://localhost:8519 (в Claude Code: launch config `research-networks`).

## Публикуване

Качване в Hostinger (ZIP през File Manager или GitHub + автоматично публикуване) и обновяване: вижте [DEPLOY.md](DEPLOY.md). Пакетът за качване се прави с `python tools/pack.py` → `deploy/site.zip`.

## Ключови конвенции

**Двуезичност.** Всеки текст съществува два пъти: `<span lang="bg">…</span><span lang="en">…</span>`.
CSS показва само активния език (`html[data-lang]`). В JS: `RN.L(bg, en)`; за обекти от JSON: `RN.T({bg, en})`;
за низове `"bg|en"` (напр. числа с различно форматиране) — също `RN.T`. Езикът се пази в `localStorage`, `?lang=en` го форсира.
Числа: `RN.nf(n, dec, 'bg'|'en')` / `RN.NF(n, dec)` (BG: `10 000`, `3,6`; EN: `10,000`, `3.6`).

**Тема (тъмна/светла).** Тъмната е по подразбиране; бутонът ☀/☾ в навигацията превключва (`RN.setTheme`), изборът се пази в `localStorage`
(`renet-theme`), а `?theme=light` я форсира. Малък inline скрипт в `<head>` на всяка страница я прилага преди рисуване (без проблясване).
Всички цветове са CSS токени: тъмните в `:root`, светлите в `html[data-theme=light]`. Илюстрациите (`.svgbox`, `.ucArt`, `.mapBox`, `.uc-box`
и всичко с клас `.screen`) остават тъмни „екрани“ и в двата режима — SVG графиките с вградени цветове се слагат в такъв контейнер.

**Цитати.** `<sup class="cite" data-c="12,74"></sup>` → става `[12,74]` с линкове към `sources.html#src-12` и заглавие като tooltip.
Номерата са от `data/sources.json`: 1–38 = препратките на доклад 1, 39–75 = препратките на доклад 2 (k-тата препратка на доклад 2 = 38+k).
Всяко ново твърдение трябва да има цитат; информация извън бележника се отбелязва с `ext: 1` / значка „ВЪНШЕН“.

**Нова страница.** Копирайте която и да е страница, сменете `data-page`, `<meta name="rn-title">`, съдържанието и скрипта,
и добавете ред в `RN.PAGES` в `assets/js/core.js` — навигацията, футърът и плочките на началната страница се обновяват сами.

**Табове.** Подменюто на всяка страница (`<nav class="subnav" data-tabs>`) работи като табове: всеки пункт показва само
своята секция, а `#хешът` пази таба. Връзка към елемент вътре в секция (напр. `services.html#identity` или id на карта)
отваря нужния таб и превърта до елемента. Ако скрипт трябва да скочи към друга секция, да смени `location.hash`
(не `scrollIntoView`, защото секцията може да е скрита). При смяна на таб се изпраща събитие `rn:tab`.
Табът по подразбиране (когато адресът няма #хеш) е първият; друг се задава със стойност, напр. `data-tabs="network"` на NRN BG (Мрежата).
Без атрибута `data-tabs` подменюто се връща към стария режим (дълга страница с подчертаване при превъртане).

**Нова база данни.** Сложете `data/<име>.json` и я четете с `RN.data('<име>')` (кешира се). За външен API сменете само `RN.data`.
Таблиците в `data.js` (функция `table`) са общи — нов набор е ~15 реда.

## Помощни функции (`window.RN`)

`RN.data`, `RN.L`, `RN.T`, `RN.nf`, `RN.NF`, `RN.cite`, `RN.fillCites`, `RN.enhance` (reveal, броячи, цитати за нов HTML),
`RN.bars` (анимирана лентова диаграма, вкл. log скала; `v: null` = без стойност), `RN.donut`, `RN.loop` (анимация само когато елементът се вижда),
`RN.whenNear`, `RN.fiber` (фонът в hero), `RN.fitCanvas`, `RN.PAGES`. При `prefers-reduced-motion` анимациите спират и всичко се показва в крайно състояние.

## Външни зависимости

Шрифтове: Google Fonts (Geologica, Golos Text, JetBrains Mono). Карти: `d3@7.9.0`, `topojson-client@3.1.0`, `world-atlas@2.0.2` от jsDelivr —
само на networks, science и bulgaria; без мрежа картите показват съобщение, а останалото работи.
