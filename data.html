Място за нови бази данниRoom for new databases

Всеки набор е отделен JSON файл в папката data/ и се зарежда през една функция (RN.data). Нова база данни — файл или външен API — се добавя, без да се пипат страниците.Each dataset is a separate JSON file in the data/ folder, loaded through a single function (RN.data). A new database — a file or an external API — can be added without touching the pages.
